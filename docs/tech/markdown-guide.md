# Markdown 写作指南

本知识库所有文章都用 Markdown 编写。这是一份快速上手指南。

## 标题

使用 `#` 表示标题，层级从一级到六级：

```markdown
# 一级标题
## 二级标题
### 三级标题
```

## 文本样式

- **粗体**：`**粗体**`
- *斜体*：`*斜体*`
- ~~删除线~~：`~~删除线~~`
- `行内代码`：`` `行内代码` ``

## 列表

无序列表用 `-`，有序列表用数字：

```markdown
- 项目一
- 项目二
  - 子项目

1. 第一步
2. 第二步
```

## 代码块

使用三个反引号包裹，并可指定语言以启用语法高亮：

````markdown
```js
function hello() {
  console.log('Hello, 知识库!')
}
```
````

## 链接与图片

```markdown
[链接文字](https://example.com)
![图片说明](/images/pic.png)
```

## 引用与提示框

VitePress 支持多种提示框，写文章时很好用：

```markdown
> 普通引用

::: tip 提示
这是一条提示。
:::

::: warning 注意
这是一条警告。
:::
```

渲染效果：

::: tip 提示
这是一条提示。
:::

::: warning 注意
这是一条警告。
:::

## 表格

```markdown
| 列一 | 列二 |
| ---- | ---- |
| 内容 | 内容 |
```

# 如何阅读一本书

> 读书笔记示例 —— 展示如何在一篇文章里组织「摘录 + 思考 + 行动」。

## 书籍信息

- **书名**：如何阅读一本书
- **作者**：莫提默·J. 艾德勒 / 查尔斯·范多伦
- **标签**：#阅读方法 #自我提升

## 核心观点

阅读分为四个层次，层层递进：

1. **基础阅读**：读懂字面意思。
2. **检视阅读**：快速浏览，判断这本书值不值得读。
3. **分析阅读**：深入理解，完整消化一本书。
4. **主题阅读**：围绕一个主题，对比多本书。

## 我的思考

大部分时候我停留在「检视阅读」，读得多、记得少。这本书提醒我：

- 读之前先问自己「我想从这本书里得到什么」；
- 读的时候主动提问、做笔记，而不是被动接收；
- 读完输出一篇笔记，才算真正消化。
